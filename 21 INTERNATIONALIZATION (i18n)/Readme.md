1. learnt:
   1. Using the `_locales` folder
   2. `_locales/<lang>/messages.json` : Holds translations.
   3. `__MSG_key or name__` : Lets Chrome replace text automatically in the manifest or HTML.
   4. `chrome.i18n.getMessage()`  : Use inside scripts for localized strings.
   5. `default_locale`  : Fallback language if translation missing.
